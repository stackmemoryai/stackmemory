PHILOSOPHY

Design principles

01
Context is a call stack
Frames nest hierarchically. A bug fix lives inside a feature frame. Scoped retrieval returns the relevant subtree, not a flat list.
02
Serialize to disk
Context windows compress and vanish. State serialized to JSON/Markdown on disk survives indefinitely. Compaction-proof by design.
03
Standardize the intersection
Core API works identically across Claude, Codex, and OpenCode. Provider-specific capabilities through explicit opt-in.
04
Automate the tedious
Hooks handle mechanical work: checkpointing, syncing, capturing theory updates. The agent decides what to work on.
05
Reject needless complexity
Every rejected integration followed the same pattern: large binary, narrow use case, maintenance burden exceeding value.
